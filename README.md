# Local Event Website & Business Directory

A modern, high-performance community event and local business directory built with Next.js 15, React 19, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Event Discovery**: Search and filter local events by category, date, and geographic hierarchy (Country > Region > City).
- **Business Directory**: Comprehensive local venue and service provider listings.
- **Organizer & Venue Hubs**: Dedicated profile pages showcasing upcoming events and location details.
- **Event Submission & Claiming**: User workflows to submit events and claim business profiles.
- **Saved Events**: Bookmark events locally to keep track of upcoming plans.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Styling**: [React 19](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/), [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 📦 Getting Started

### Prerequisites

- Node.js (v18.18.0 or higher recommended)
- npm or yarn

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm run start
```

## 🌐 Deployment on Vercel

The easiest way to deploy this Next.js app is using the [Vercel Platform](https://vercel.com/new).

1. Import this repository into Vercel.
2. Vercel automatically detects Next.js settings.
3. Click **Deploy**.
